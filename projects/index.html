Projects

Software and formats

Many of our early efforts were incorporated into standards such as FHIR and the XML representation of DICOM. JSON has since emerged as the interoperable data format, and it is what the new AI systems speak, so our current work is built on JSON and on AI.

Current work

Chart

Chart is an AI-based medical assistant. It helps a healthcare professional get through the documentation and coding and get back to the patient. Chart is standards based, with FHIR under the hood, and runs on the web. It replaces XChart.

chart.openhealth.org

UTHE

The Universal Transformation Healthcare Engine converts between healthcare document formats, in either direction: JSON, XML, HTML and HL7, including FHIR. Mappings can be customized for specialized fields.

About UTHE

JSON Schemas for Healthcare

JSON Schema formats for healthcare data. This is where our standards work moved after the XML era.

Loxation

Loxation builds phone-to-phone Bluetooth mesh communications for crowds where cell service collapses: the PLURNet app and Loxation Mesh Routers that extend the mesh across a venue. A short clip of the iOS app is below.

Earlier work

XChart 2001
Our original open-source, XML-based health record, built to be easier than paper. Why open source, and the release archive.
Opnote generator demo 2001
An XML and XSLT demonstration that generates operative notes from forms. Technical notes.
XEditor 2000
An XML vocabulary for edit lists, compiled with XSLT into transformations that carry out the edits.
