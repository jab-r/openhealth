Standards archive

Specifications, 1998 to 2003

The Open Healthcare Group's specifications, reference documents, software and talks from the XML era, kept here as published. Links go to the original documents, and some of them show their age. Parts of this work were later incorporated into FHIR and the XML representation of DICOM; the current work is on the projects page.

Specifications

RDDL: Resource Directory Description Language 2001
An XHTML-based format for describing what a namespace URI points to: schemas, stylesheets and documentation. Also published at rddl.org.
XMTP: XML MIME Transformation Protocol 1998, 2001
A mapping of RFC 822 and MIME messages to XML and RDF. The 1998 version is also kept.
XMOP: XML Metadata Object Persistence 1998 to 1999
Serializing component objects to XML, with the SODL object description language and early SOAP and XML-RPC proxy generators. Browse the files.
XSet 2000
An XML property set description of XML itself.
XML Namespace Catalog Format 2000 to 2001
A catalog format for resolving namespace names to resources.
XSQL
A simple XML representation of SQL statements, for XML to SQL and SQL to XML translation.
XEditor 2000
An XML vocabulary for edit lists, compiled by XSLT into transformations that carry out the edits.
RDF syntax work 2001
Abstract and surface syntax drafts, extracting and reifying RDF from XML, RDF regular expressions, and the QName quagmire.
W3C Web Ontology Working Group contributions 2002
An OWL non-XML syntax primer, the datatypes task force documents, and an OWL media type proposal.
ASTM E31.25 XML healthcare DTDs 2000
Draft DTDs and RELAX NG schemas for XML healthcare documents, including a clinical header, an operative report, and DICOM structured report DTDs.
